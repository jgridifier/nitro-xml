# Real Office-authored corpus: sources

Real files written by Microsoft Office, each redistributable under a permissive or public-domain licence. One table per format, with source URL, SPDX licence, licence evidence URL, author, retrieval date, authoring app and detected features:

- [.xlsx / .xlsm / .xltx](xlsx/SOURCES.md) (#32)
- [.docx / .docm / .dotx](docx/SOURCES.md) (#95)
- [.pptx / .pptm / .potx](pptx/SOURCES.md) (#96)

Machine-readable rows (the `fixtures/manifest.json` fields from #4) are in `<format>/sources.json`. Allowed licences: public domain (incl. U.S. government works), CC0, CC-BY-4.0 (attribution recorded), MIT, Apache-2.0, BSD. CC-BY-SA, NC, ND and unknown licences are rejected, and nothing over 10 MB is committed.
