Method

Engine
upstream ChristopherVR/ooxml TypeScript engine, pinned at commit e66aaec (the correctness oracle and speed baseline)
Browser
Google Chrome (headless) 156.0.8078.4 via Playwright; cross-origin-isolated page (COOP/COEP on the perf harness only — not required by the shipped package)
Host
Intel(R) Xeon(R) Processor, 8 logical cores, linux 6.12.94+; runner: local
Timing
first_paint_ms: navigation start to first painted frame (PerformancePaintTiming "first-paint"); parse_ms: engine parse call only; tti_ms (warm): time to interactive after first paint (harness interaction start, to avoid counting harness scroll steps)
Memory
JS heap size via performance.memory.usedJSHeapSize after a cold parse with the model retained. This is an approximate lower bound — it does not include off-heap WASM linear memory, which is reported separately when WASM data exists.
Fairness
Same machine, same Chrome build, same fixtures per run. Losses are shown as prominently as wins. Cross-host rows (data from different machines) are flagged as not comparable.
Source
perf/history.jsonl in the repo; harness scripts in perf/; this page generated by scripts/ci/gen-benchmarks.mjs
